Como Funciona la red en la implementacion de este proyecto

En este apartado podemos visualizar el diagrama de funcionamiento de los dispositivos y la conexion que hay entre cada uno de ellos, la forma de comportamiento que tendran y el flujo que existe en esta arquitectura.

Sección 1 Conexion

La red 192.168.30.0/24 conecta todos los equipos mediante un router. Una máquina virtual con Ubuntu Server 24.04 (IP fija 192.168.30.10) ofrece DHCP, DNS y FTP. Las demás máquinas virtuales (TrueNAS, Samba, Apache, IIS, PBX y Zabbix) son sus clientes y reciben de él IP y dominio servidores.local.

Sección 2 Servicios

Los tres servicios comparten IP, pero cada uno usa su propio puerto. El DHCP (UDP 67) reparte direcciones del .100 al .200. El DNS (puerto 53) traduce los nombres de servidores.local a su IP. El FTP (TCP 21 y puertos pasivos 40000 a 40100) permite subir y descargar archivos.

Sección 3 Arranque

Al arrancar, cada máquina pide IP al DHCP (Apache .100, Samba .101, IIS .102, TrueNAS .103, Zabbix .104 y PBX .105) y después usa el DNS para localizar a las demás por nombre. El DHCP debe ser el único de la red, el servidor debe tener IP fija y el firewall debe permitir los puertos de los tres servicios.

Sección 4 Flujo

El cliente obtiene IP del DHCP, resuelve nombres con el DNS y se conecta al servicio que necesita.
