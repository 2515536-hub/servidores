TRUENAS

¿Que es TrueNAS?

TrueNAS es un sistema operativo de código abierto basado en FreeBSD, diseñado para proporcionar una solución de almacenamiento en red (NAS) completa y potente. Es ampliamente utilizado en entornos empresariales para centralizar y gestionar datos de manera eficiente.

Características principales de TrueNAS:

Almacenamiento centralizado

TrueNAS permite centralizar el almacenamiento de datos, lo que facilita la gestión y el acceso a archivos desde múltiples dispositivos y ubicaciones, colcando multiples dispositivos de almacenamiento

Seguridad y protección de datos

TrueNAS ofrece características avanzadas de seguridad, como cifrado de datos, control de acceso basado en roles y copias de seguridad automáticas para proteger la información almacenada.

Compatibilidad con múltiples protocolos

TrueNAS es compatible con una amplia gama de protocolos de red, como SMB/CIFS, NFS, iSCSI y FTP, lo que permite la integración con diferentes sistemas.

Protocolos que usa:

  • SMB/CIFS (Server Message Block/Common Internet File System)
  • NFS (Network File System)
  • iSCSI (Internet Small Computer Systems Interface)
  • FTP (File Transfer Protocol)

Ventajas de usar TrueNAS:

  • Almacenamiento centralizado y eficiente
  • Seguridad avanzada y protección de datos
  • Compatibilidad con múltiples protocolos de red
  • Escalabilidad para adaptarse a las necesidades de almacenamiento
  • Interfaz web intuitiva para la administración del sistema

Desventajas de usar TrueNAS:

  • Requiere conocimientos técnicos para la configuración y administración
  • Puede ser más costoso en comparación con soluciones de almacenamiento más simples
  • Dependencia de hardware compatible y confiable

Funcionamiento:

TrueNAS funciona como un sistema operativo que se instala en un servidor o dispositivo de almacenamiento dedicado. Una vez configurado, permite a los usuarios crear y administrar volúmenes de almacenamiento, establecer permisos de acceso, configurar copias de seguridad y monitorear el estado del sistema a través de una interfaz web intuitiva. zfs es el sistema de archivos utilizado por TrueNAS, que proporciona características avanzadas como instantáneas, replicación de datos y protección contra la corrupción de datos. Los usuarios pueden acceder a los pools de almacenamiento a través de los protocolos compatibles, lo que facilita la colaboración y el intercambio de archivos en entornos empresariales. pools con raidz2 y raidz3 permiten a los usuarios configurar arreglos de discos con tolerancia a fallos, lo que garantiza la disponibilidad de los datos incluso en caso de fallos de hardware.

Casos de uso y valor de TrueNAS:

Almacenamiento crítico y compartido

TrueNAS destaca en entornos con archivos institucionales, backups, almacenamiento de máquinas virtuales, bibliotecas multimedia o compartidos de trabajo. Su arquitectura ZFS permite centralizar la capacidad y reducir la pérdida de datos por fallos de disco.

Disponibilidad y recuperación

Es una excelente opción para organizaciones que necesitan instantáneas, replicación, resiliencia y capacidad de gestión desde una interfaz intuitiva. Ideal para despliegues con crecimiento gradual y requerimientos de alta disponibilidad.

Información técnica útil

Aspecto Detalle
Puertos principales 80/TCP y 443/TCP para la interfaz web, 22/TCP para SSH si está habilitado, y 445/TCP para SMB, 2049/TCP para NFS y 3260/TCP para iSCSI.
Requisitos comunes Hardware compatible con RAM suficiente, discos duros o SSD apropiados, y preferiblemente ECC en entornos con datos críticos.
Protocolos soportados SMB/CIFS, NFS, iSCSI, AFP/compatibilidad, FTP y servicios de sincronización/replicación según la versión.
Arquitectura clave ZFS, pools, vdevs, instantáneas, protección contra corrupción y estrategias de mirroring o RAID-Z.
Consideraciones Es clave dimensionar la capacidad, la tolerancia a fallos y el tipo de discos para evitar pérdida de datos y degradación del rendimiento.

Como se virtualiza:

Info! Puedes descargar la ISO de TrueNAS aqui
Info! Puedes descargar el .exe de VirtualBox aqui

    Creacion de la VM

  • Con la iso descargada se crea una nueva VM asignando un nombre y la misma configuracion
  • Se asignan los recursos de hardware, RAM donde aqui se asigno 4GB y 2 Nucleos
  • Se asigna el disco duro virtual que sea dinamico y no reservado
  • Una vez creada la VM, se inicia y se configura y en discos agregando la iso descargada
  • En controlador SATA se agregan los discos virtuales necesarios
  • Se da click en crear
  • Se asigna la cantidad de espacio que se necesite
  • Asi quedaria la implementacion y se da doble click sobre cada uno de los discos creados
  • Asi quedaria su implementacion

    • Configuracion e instalacion de TrueNAS

  • Se da click en aceptar y se inicia la VM
  • Seleccionar install/updgrade
  • Posicionarse en el almacenamiento y con la tecla "espacio" presionarla para seleccionarla
  • Seleccionar "Yes" para que borre la informacion del disco donde se instalara TrueNAS
  • Seleecionar "Configure using web UI"
  • Seleecionar "Yes" para los componentes virtualizados y esperar a su instalacion
  • Una vez termine reiniciar y quitar el disco de instalacion
  • En la configuracion de la VM en el apartado de red modificar la configuracion de red a adaptador puente y permitir todo, para poder acceder a la interfaz web de TrueNAS
  • Iniciar la vm y esta sera la pantalla que aparecera, con esa ip se accedera a la interfaz web en un navegador
  • En esa interfaz se creara una nueva contraseña
  • Esta es la interfaz dashboard de TrueNAS
  • En el apartado de Storage y Disks verificaremos que se encuentren los discos que creamos
  • Ahora en Storage crearemos los pools
    • Info! Pool de almacenamiento (Storage Pool): Agrupa discos físicos o capacidades lógicas para repartir y gestionar el espacio de los volúmenes de forma transparente y sin interrupciones.
  • Se asigna un nombre al pool
  • Ahora un tipo de agrupacion teniendo muchos, pero en este caso usaremos el Mirror
    • Info! la agrupación tipo Mirror (espejo) es un arreglo de discos que guarda una copia exacta e idéntica de los mismos datos en todos los discos que forman parte de ese grupo
  • Aqui se seleccionaran los discos
  • Hasta aqui seria necesaria la configuracion a menos de tener que colocar algo mas especifico, por ultimo se creara el pool
  • Asi estaria la configuracion de los pools
  • Ahora en el apartado de Dataset se agregara uno a nuestro pool para la carpeta en red
  • Se le asigna un nombre y se guarda
  • Ahora en credentials y users para crear nuevos usuarios y daremos click en add.
  • Le asignaremos un nombre, contraseña, forma de acceso y crearemos una carpeta para nuestro usuario con los permisos que queremos proporcionar
  • Lo haremos con los usuarios que queramos crear, teniendo que estar asi la configuracion
  • Ahora en System y services
  • Vamos a prender los servicios que necesitamos, en este caso SMB
  • Ahora en Shares haremos click en add en el servicio para agregar la carpeta que se va a compartir
  • En el explorador de archivos en red, en la ruta del explorador colocaremos la ip de nuestro servidor \\ip_del_servidor, le pondremos las credenciales correspondientes
  • Nos dejara acceder a nuestra carpeta creada para nuestro usuario

Conclusión:

TrueNAS es una solución de almacenamiento en red confiable y versátil que ofrece características avanzadas para la gestión de datos. Su enfoque en la seguridad, compatibilidad con múltiples protocolos y escalabilidad lo convierte en una opción popular para empresas y usuarios que buscan una solución de almacenamiento robusta.
