Módulo de Servidores Web

Este módulo aborda la teoría y la parte técnica del funcionamiento de los servidores web, con especial atención a Apache e IIS. Se revisan su arquitectura, protocolos, alojamiento de contenido, seguridad y forma en que publican sitios y aplicaciones en una red corporativa o de producción.

Apache

Apache es un servidor web multiplataforma que publica páginas, APIs y servicios en HTTP/HTTPS. Su funcionamiento se basa en módulos, hosts virtuales y control de permisos, lo que lo hace muy flexible para entornos empresariales, pruebas y despliegues web distribuidos.

IIS

IIS es el servidor web de Microsoft para Windows Server. Su funcionamiento está orientado a sitios internos, aplicaciones .NET, autenticación, certificados SSL y administración desde la propia infraestructura Windows. Es ideal para entornos donde la integración con AD y servicios empresariales es clave.
